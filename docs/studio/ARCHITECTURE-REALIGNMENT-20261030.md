repair. Keep the approved owner-local popup hub and genuine upstream document-modal

Change graph source resolution to follow lexical scope instead of collecting
every state name as document state. Document state and scoped state with identical
names must never alias. A source-only edit of a private scope changes its template
default, while runtime writes stay occurrence-local. A controlled nested graph
edit must select its containing graph node(s), check every graph revision and
write back through validated parent operations. Ambiguous or unresolved ownership
refuses atomically. Private graphs use local history; only source-backed graphs
receive canonical source history. Source import/export must retain these owners.

Expose exact graph authoring associations through a public code registration
contract rather than Studio component-name inference. Reconcile public discovery
with implemented scope/persistence behavior and version changed tool contracts.
Retained source formats are not migrated or reinterpreted implicitly.

Remove the flat state-name/global-history assumption and stale current-status
claims. Do not restore compulsory graph toolbar/inspector/forms/family picker or
introduce a parallel runtime, application language or persistence engine.

Persistence policy: explicit bidirectional document graph bindings in Studio opt
into authored configuration and canonical history. Private scoped state remains
runtime state. Controlled scoped writes delegate to their owner; they persist only
when that ownership chain terminates in authored source. A standalone application
chooses its host policy. Durable application graphs require the existing authorized
application resource/action path; a graph interaction never grants that authority.
