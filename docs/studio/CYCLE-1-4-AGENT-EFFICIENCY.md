### Diagnosis and evidence

This is primarily a VICT integration/contract decision, not proof of a Mastra capability limitation. The installed Mastra stream types include reasoning-start/delta/end, reasoningText and reasoning output. Official reference: https://mastra.ai/docs/guides/streaming . Actual availability depends on model/provider; the configured GLM endpoint's emitted reasoning payload has not been verified. Model execution must not be described as thinking-disabled solely because its reasoning is absent from Chat.

`packages/contracts/src/agent-stream.ts` explicitly excludes hidden chain-of-thought/reasoning content from the frozen `vict.agent-stream@1` surface. `packages/mastra/src/adapter.ts` normalizes selected text/tool/lifecycle events and ignores unhandled chunks. `apps/studio/src/lib/server/designer-agent.ts` forwards supported normalized events, not a reasoning channel. `AgentChat.svelte` consequently cannot expose a missing channel through a disclosure control alone. The prior suggestion that this was only a presentation limitation was incomplete; this correction is retained.
