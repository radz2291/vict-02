The left dock uses accessible Chat / Layers tabs with both tab contents mounted. The active conversation, draft and turn are not replaced by tab navigation. Layers / Inspect use the same local `LayersInspectPanels` in Studio and the disposable showcase: independent plain header buttons, hidden-but-mounted contents, keyboard/pointer divider, bounded saved split and remembered sidebar width/tab/collapse preference. Shared read-only SourceDetails has an embedded presentation without a second close header or mount-time focus grab; Layers / Structure selection points to the same source facts. Explicit editing still uses floating canvas tools.

Document is a normal layout column; it never paints over the canvas. Its shared `DocumentPanels` uses one active section key, so Data / Actions / Source cannot expand together. Clicking the active header can collapse all. Contents remain mounted, including unapplied drafts. Desktop opening/resizing takes canvas width. At narrow widths, Document reflows below the canvas in the layout; short workspaces can scroll vertically. This keeps every panel reachable without an overlay or an unusably thin canvas. Bottom Structure remains mounted and independently resizable/expandable.

Because Data, Source and floating editors can now coexist in the layout, existing draft protection is explicitly applied to the other editable surfaces and their Apply entry point. A pending data/property draft disables source editing; a pending source draft disables other data/property fields and refuses other canonical transactions. Explicit Apply source remains the only local source-draft handoff. Closing Document remains refused while its draft is pending. Folding/tab navigation preserves the draft; it does not grant editing or storage authority.
