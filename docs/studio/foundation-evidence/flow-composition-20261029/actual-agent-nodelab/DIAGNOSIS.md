Independent source investigations reproduced these framework defects:

- Exact graph data/operation grammar is absent from public composition knowledge.
  Workspace discovery names the graph schema but does not define its payload.
  Recipe-only palette discovery finds the old read-only canvas, while catalog
  discovery can find the seedless workspace.
- Read-tool presentation accepts inputs rejected by actual section validation.
  Pre-invocation feedback loses the diagnostic, so two failed calls have no
  validated input or settled result. Their exact arguments remain unknown.
- The agent incorrectly requested recipe/shorthand IDs as registered components.
  That refusal was appropriate. Independently valid pages in the same partial
  bundle were also discarded by knowledge tracking, causing avoidable rereads.
- Graph@1 permits scalar numbers but the standard VICT slider emits numberList.
  Scoped UI supports that type, while the graph field adapter cannot persist it.
  A per-slider adapter would repeat the rejected fixed-control architecture.

These defects do not prove the sole cause of provider failure or all elapsed
time. Repairs must preserve Graph@1 and introduce a versioned generic parameter
contract, precise discoverable grammar and actionable bounded feedback. A retry
must occur only after targeted verification and activation, retain this failure,
and author through Studio chat rather than coding tools.
