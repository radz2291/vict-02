## Primary source

`examples/ui-authoring-proof/src/lib/product/documents.ts` constructs only `vict.ui-document@1` data. It owns identity/navigation, queue rows, status bindings, evidence/findings, decision/correction forms, rejection reason, activity, empty states, lifecycle next-action wording, and responsive composition. The exported documents are serializable canonical source; no Svelte imports occur in them. The application declares both screens in document mode and includes both digests in application identity. Detail source advances from revision 1 to 2; the application source revision advances to 2. Normal authoring saves begin at stored revision 2 and advance to 3. Legacy stored documents retain their recorded revision authority and remain readable.

The read-only `inspectionQueue` resource declaration describes a rendering projection `{ inspections: inspection.list.rows }` of existing data. It adds no stored business facts, operation or adapter. It allows the joint compiler to resolve the queue collection and child inspection fields without a shadow UI model or false domain properties.

`compile.ts` jointly compiles the product and the authoring working source against the same descriptor catalog. Product detail reads valid saved canonical source from the existing authoring store and jointly recompiles it, including applicationVersion; incompatible bytes stay preserved and a bundled fallback is disclosed. Browser evidence shows a normal Text size edit, Save, then the actual product title rendered at 42px. The queue is authored source too; this bounded browser editor continues to edit detail only.

## Reusable bridges and mounting

`DocumentHost` accepts explicit `extensionDescriptors` and `extensionImplementations`. Each code registration matches extension ID, revision and rendererImplementationId. Components receive `{ props, occurrenceKey, nodeId }`. Dispatch remains on authored elements/forms; extensions receive no action authority. Current compiled instructions support props only. Descriptors declaring events/slots, absent implementations or competing identities fail visibly and produce render diagnostics. This is deliberately not a promise of opaque extension-internal visual editing.

`stateValues` accepts host orchestration values only for declared local-state keys of matching primitive types, preserving other field values and resetting before applying supplied values. It seeds SSR consistently. Invalid supplied keys are rejected with `UI_RENDER_STATE_VALUE_REJECTED`. This does not change the neutral document contract.

Mount the same descriptor and implementation arrays in product DocumentHost and EditorCanvas; pass canonical localState plus ephemeral stateValues. Import `@victframework/ui-svelte/styles.css` once and mount a `.vict-app` scope. Set a named `inspection` inline-size container for this document's container rules. A different consumer may provide its own compatible semantic tokens; no arbitrary Svelte import or inspection-specific branch was added to the generic renderer.
